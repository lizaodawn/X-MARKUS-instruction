# X-MARKUS Introduction

X-MARKUS is an analytic platform that accepts ENTMARKUS, COMARKUS and IMMARKUS annotation files.
- The user can launch X-MARKUS from https://xmarkus.xmarkus.org or download the X-MARKUS package to run from local disk
- It is written in pure JavaScript, HTML, and CSS.
- It is open-sourced.
- It keeps the architecture simple & privacy-friendly.  It can run JavaScript locally, 
  with no need for cloud storage or an online database.
- It avoids the use of built-in browser storage technologies like [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) or [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API), which 
  browsers may delete without notice to the user (e.g. after a certain period of inactivity).
- It simplifies handling of large files, especially images.


The X-MARKUS platform contains three tools and a link to the spatial tool:
1. A converting tool to convert ENTMARKUS, COMARKUS, or IMMARKUS data into an XML file for later analysis.
2. A searching and filtering tool to analyze the converted data
3. A visualisation tool which allows one to visualise the relations between events and features
4. An independent tool MUNDa which allows one to analyze the converted data spatically
